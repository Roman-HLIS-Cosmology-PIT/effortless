# Effortless: EFFicient Optimal image ReconsTruction using LESS memory

Effortless, previously known as Fast [IMCOM](https://github.com/Roman-HLIS-Cosmology-PIT/pyimcom) (IMage COMbination), is a linear image reconstruction algorithm that offers control over point spread functions in output images, designed for the [weak gravitational lensing cosmology program](https://roman-hlis-cosmology.caltech.edu/) with the [Nancy Grace Roman Space Telescope](https://science.nasa.gov/mission/roman-space-telescope/roman-for-scientists/) and beyond.
